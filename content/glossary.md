# Glossary

This glossary explains terms currently used in the Item Bank Explorer.

| Term | Definition |
|---|---|
| Item | A questionnaire element represented by an individual variable, which may be one statement in a larger question. |
| Item UID | Stable identifier for an item across its versions. |
| Item version | A particular form of an item, with its own identifier and administration metadata. |
| Variable | A field in a study dataset, either observed or calculated. |
| Variable code | Name of a variable in the corresponding dataset. |
| Topic | The theme under which an item is organized. |
| Topic ID | Identifier of a topic. |
| Derived variable | A variable calculated from one or more existing variables. |
| Index / Index UID | Name and stable identifier of an entry in Derived Variables. |
| Construct scale | A derived variable combining items to represent a measured construct. |
| Study | IEA research program, such as ICILS. |
| Cycle | A study administration; **Year** specifies the calendar year. |
| Instrument | Questionnaire or respondent instrument. |
| Population | Respondent group, such as Student or Teacher. |
| Target | The target grade recorded for the instrument. |
| Wording | The text presented to respondents. |
| Response type | Structure of the item's responses. |
| Response scheme | Answer values and labels, including checkbox coding when relevant. |
| Missing-value scheme | Values used to encode missing responses. |
| PUF | Indicates whether a variable is included in a public-use dataset. |
| RUF | Restricted-use file access; some information can be explored in the Item Bank but not downloaded as PUF data. |
| Composition over time | How the membership of items and their versions changes across the available years. |
| Export Selection | Cart containing item versions selected for Excel export. |

The Item Bank documents questionnaire metadata; it does not directly provide every study dataset.
