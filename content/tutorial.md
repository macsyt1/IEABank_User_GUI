# Item Bank Explorer: Search and Export Guide

## Choose where to begin

**Items** lets you locate questionnaire items by study, year, population, target grade, instrument, response type, PUF availability, or text search. The results show item identifiers, names, associated studies, years and version counts.

**Derived Variables** lists indices and constructed scales, their associated studies and years, components and available versions. Use **Construct scales only** to restrict the results.

**Topics** groups questionnaire items by theme. Its table displays an ID, name, associated studies, years, item counts and a Details action.

**Instruments** displays available questionnaires with study, year, cycle, target grade, instrument, item count and derived-variable count.

## Search and review

Use the sidebar filters in each area, optionally add keywords, and open **Details** for more information. Keyword searches look at several relevant fields, not necessarily every column. Use **Reset filters** to return to the full list.

- **Item details:** inspect versions, wording, response and missing-value schemes, population, available years, and item versions over time.
- **Derived-variable details:** inspect index versions, member items and composition over time.
- **Topic details:** review associated items and longitudinal composition; the topic name is shown in the dialog heading.
- **Instrument details:** review questionnaire items with their names, versions, variable names, response types, derived variables and PUF flags.

Not all items belong to derived variables. A dash in a longitudinal view can indicate an item that was administered but not a member of that index or topic in a given year.

## Export selection

Select rows and choose **+ Add selected**, or add an item or version from a Details dialog. The cart collects distinct administered item versions and avoids duplicate entries. In **Export Selection**, use **Remove selected** to drop specific versions, **Clear cart** to empty the selection, and **Download Excel** to export the available metadata.

## Report a problem

Use **Report an issue** if you encounter broken functionality, incorrect information or have an improvement suggestion. You may include one PNG/JPEG screenshot (up to 5 MB). Reports are submitted automatically as GitHub issues. Screenshots and optional contact email are stored privately and are not published to GitHub. Do not include student data or confidential information in the screenshot.
