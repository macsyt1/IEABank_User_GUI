# Latest news

Welcome to the IEA Item Bank Explorer. This page highlights changes to the application and available help.

## October 2026: Explorer improvements

Recent updates include a refreshed questionnaire and topic browsing experience, clearer variable labels, support for removing individual selections from the export cart, and a dedicated Tutorial and Glossary.

**Feedback:** Use **Report an issue** to send bug reports, data corrections or suggestions to the IEA Research and Analysis team. Reports are reviewed before any GitHub issue is created.

The Item Bank is still evolving; additional content and functionality will be introduced in future releases.
